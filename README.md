臺灣時序是一份可操作的歷史地圖，收錄臺灣與澎湖從 **1624 年至 1996 年**的地方沿革。沿著時間軸，你可以查找地名何時改變、城堡與港口在各年代扮演什麼角色，或從一處熟悉的地標讀到背後的史料。

## 你可以怎麼用

- **從今天的地名找到舊稱。** 搜尋「淡水」或「滬尾」都能找到相關條目，「台」與「臺」也可通用。點開地點卡即可比較同一地點在不同年代的稱呼與記載。
- **在同一視野比較年代。** 拖動時間軸或選取年份，查看該年的地名、行政據點及事件。可選用連續播放快速瀏覽，也可停在單一年份逐筆閱讀。
- **把舊圖疊回同一片地形。** 六個快照提供中研院歷史圖幅。圖幅選單標示原圖年代，可在同一視野對照地點與現代位置。基本海岸、河川、地形隨站點提供，歷史圖磚與現代街道圖層需要連線。
- **分享有脈絡的地圖。** 「分享」會保留所選年代、圖層、地點與縮放視野，適合用在課堂、地方走讀或討論。手機可展開當年紀事和閱讀欄，純文字版也能直接連到對應的互動地圖。
- **沿著來源讀下去。** 每處地點、事件、年代導讀與歷史據點都有出處。發現需要修正的地方時，可從「導覽」開啟修正單，下載含地圖連結及條目資訊的文字檔，交給編輯者。

### 操作速查

| 操作 | 方式 |
| --- | --- |
| 平移與縮放 | 拖曳、滾輪或雙指手勢。地圖取得鍵盤焦點後，方向鍵平移，`+` 或 `−` 縮放 |
| 切換年代 | 點年份或拖曳時間軸，亦可使用 `←` 和 `→`。空白鍵播放或暫停 |
| 尋找地點 | 按 `/` 開啟搜尋，輸入地名、事件或年份 |
| 換圖層與讀詳情 | 在「圖層」選擇要看的資料，點選地標開啟沿革及來源。手機可點年代標題展開閱讀欄 |

## 如何讀這張歷史地圖

11 個快照涵蓋 **1624、1662、1684、1876、1884、1895、1908、1914、1945、1987 與 1996 年**。每個年份選錄當年可查證的地點和事件。查不到某一處在某年的記錄，表示目前尚未收錄該年資料。現代海岸、河川與地形提供共同定位參照，歷史據點採概位。比對歷史圖幅時，請同時留意圖幅標示的測繪年代。 [編輯方法與圖資](https://victorfu.github.io/taiwan/atlas/method.html)

地方記錄與年代導讀引用檔案、館藏、地方志與研究文獻，並盡量標示可回查的書目、頁碼或段落。例如何處曾是澎湖巡檢司署址，資料條目會列出不同記載。2026 年 11 月 18 日，Codex AI 分組核讀了 43 筆地方年代記錄、21 則事件、11 篇導讀與 60 筆分年據點。 [完整參考文獻](docs/references.md) · [史料審閱與勘誤紀錄](docs/review/)
