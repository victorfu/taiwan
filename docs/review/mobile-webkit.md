# iPhone 尺寸行動 WebKit 驗收

**正式版驗收通過。** 對版本 `0d605ce8a1bbd61aa1537fa3efc5f49064d9ff7cba008182dad3d5365695c008` 重跑下列全部流程。兩代 WebKit 在兩種裝置尺寸的四組測試皆通過。新增地圖表面的觸控事件處理後，四組均能點按「大員」地標按鈕，打開對應安平古堡的地點卡，網址保留 `place=castle`。低高度橫向仍可點按地圖縮放、切換年代，再回直向繼續閱讀。窄橫向地圖為 329 × 179，寬橫向為 480 × 162。

2026 年 11 月 18 日，使用 Windows 上的 Playwright 1.64.1 搭配 WebKit 27.2（建置 2370），另以 Playwright 1.44.0 搭配 WebKit 17.4（建置 2003）執行相同流程。兩組均啟用行動版 viewport、觸控與繁體中文。測試僅連至本機，安平導覽與切換圖層均使用網站的可見控制項。

| 模擬裝置 | 直向可視區域 | 橫向可視區域 | 像素倍率 |
| --- | --- | --- | --- |
| iPhone 13 | 390 × 664 | 750 × 342 | 3 |
| iPhone SE | 320 × 568 | 568 × 320 | 2 |

尺寸單位為 CSS 像素。橫向案例調整同一個頁面的 viewport，藉此檢查狀態保留與重新排版。iOS 原生軟鍵盤、Safari 網址列伸縮、安全區、實體雙指手勢及檔案 App 流程仍須在 iPhone 上驗證。

## 操作紀錄

| 驗收項目 | 實際觀察 |
| --- | --- |
| 首頁與時間軸 | 兩種直向尺寸均顯示 1624 年，頁面寬、高與 viewport 相同。點選下一個年代到 1662 年，再回到 1624 年。 |
| 地圖觸控 | 點按大員地標打開安平古堡條目。點按地圖放大、縮小，網址中的縮放層級相差一級。 |
| 搜尋與鍵盤 | 點按輸入框，輸入「熱蘭遮」，用向下鍵及 Enter 選中安平古堡，在來源年代看見「大員」地點卡。 |
| 閱讀與圖層 | 放大閱讀欄再縮小，接著關閉山岳地形。分享網址保留地形關閉狀態。 |
| 安平導覽 | 從導覽選單啟動安平故事，每站用觸控點選「下一站」，第六站到達 1895 年德記洋行。 |
| 分享與還原 | 點「分享」後，原生剪貼簿的寫入請求成功。測試擷取該次呼叫傳入的網址並重開，逐項比對第六站、德記洋行及關閉地形的狀態。 |
| 修正單下載 | 從第六站進入修正單，檢查自動帶入 1895 年。下載文字檔後讀回，確認檔內包含條目 ID 與當次填寫的說明。 |

## 橫向重測

初測版本 `c48ff3476ca74db36a04cd85b2595b5c73f9588d4f1c26aa2f60517736960900`。從已開啟的第六站轉橫向，750 × 342 下可操作 480 × 162 的地圖及時間軸。568 × 320 下地圖容器高度縮為 0。

修正版 `7d1b8e623b93f3374e93334ce3322cfae38957a2b094886abaae8cd2f34688de` 在兩個 WebKit 版本均通過完整流程。568 × 320 橫向顯示約 329 × 179 的地圖，750 × 342 橫向顯示 480 × 162 的地圖。兩種尺寸均從第六站 1895 年切至 1908 年，點按縮小後分享參數的地圖縮放從 13 降至 12。轉回直向可展開、放大、縮小與收合閱讀欄。四種「引擎 × 裝置尺寸」組合均無頁面未捕捉的 JavaScript 錯誤。

後續建置 `c93e44d406842b0444924525d0c0850ce90d55c14d9c15cbb9fbfb0abdd7ac3e` 加入低高度地圖的工具列。WebKit 27.2 兩種尺寸皆通過。WebKit 17.4 旋轉後可再次出現地圖高度 0，持續量測到 1.5 秒仍未恢復。在同一版本、同一網址、同一個 SE 配置進行兩組交替測試，保留地圖尺寸容器查詢時，橫向媒體查詢已匹配而版面仍為直排，地圖高度為 0；在測試頁移除該容器查詢及尺寸收容樣式後，兩次都恢復橫向分欄，地圖高度均為 179。
